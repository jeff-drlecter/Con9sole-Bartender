# 自動召人卡及開團足跡

管理員／Helper 使用 `/squad_setup category:<語音分類> destination:<吹水組隊頻道>` 設定路線，可設定多個分類。Bot 只監察指定分類的普通語音房，排除 AFK、Bot。

## 開局及散團

- 至少一名真人連續留滿30秒出召人卡。事件即時對賬，5秒輪詢補漏，正常約30–35秒出卡；中途清空會重新計時。
- 召人卡顯示遊戲、模式、在場玩家、語音入口及缺額；「⚙️ 招募設定」可揀遊戲、模式及人數，全部選填。
- 提供「🎮 加入語音」、「🙋 下次叫我」、「🔔 每次都叫我」及「👥 查看／更新名單」。只有在場成員或 Admin／Helper 可改招募資料，其他可見頻道的成員可登記通知。
- 最後一名真人離開或語音房刪除，原召人卡轉足跡，保留參與者、遊戲、模式及時段。足跡繼續提供兩種通知及名單按鈕；已結束的語音不再提供加入連結。
- 首位玩家只在原卡第一次發送時 tag 一次；修改、輪詢及替補訊息不重複催問。

## 通知選項

| 按鈕 | 行為 |
| --- | --- |
| 🙋 下次叫我 | 只通知下一局同款 Game，通知時用完；想收再下一局要重新登記 |
| 🔔 每次都叫我 | 每次同款 Game 新開局都通知，直到本人取消 |
| 👥 查看／更新名單 | 更新卡上名單並私下分頁顯示完整人名，每頁20人 |

同一人同一遊戲只保留一種設定；轉選另一種直接切換，再撳同一種取消。名單按伺服器及遊戲／版本分開，**不按模式分開**；大小寫和多餘空格不影響配對。未填遊戲時用分類推斷；先出卡後才揀遊戲亦可觸發該遊戲通知。

在進行中的召人卡或新局通知卡登記，會排除該局本身，留畀再下一局。訂閱名單顯示「🙋 下次叫埋」及「🔔 每次都叫」，使用 Discord 成員顯示名稱／可點選人名；純顯示或更新名單不會 ping。

下一局達30秒門檻後，tag 已登記玩家，附召人卡連結、加入語音及兩種再預約按鈕。同一 session／遊戲最多通知一次；每次通知的成員最多20人一批，只允許指定用戶 mentions，禁止角色及 everyone。永續通知沒有跨局30分鐘冷卻；每一新局均可通知。

已在該房、Bot、已離開伺服器、未在 cache 或沒有文字頻道查看／語音房查看及連接權限的人不通知；未通知的人保留登記。卡上只顯示仍在伺服器且可見該文字頻道的真人。

## 狀態及相容

- 語音 session 存於共用 `DATA_DIR/squad_cards.json`，可用 `SQUAD_CARDS_PATH` 覆寫。訂閱、已嘗試通知及已知卡片位置存於 `STATS_DB`（一般 `/data/community_stats.sqlite3`）。需持久化，僅支援單一 Bot instance。
- 加入／取消或發通知後，同遊戲的已追蹤召人卡及足跡名單同步更新。刪除的卡會移出追蹤，沒有讀取或重發歷史頻道訊息。
- 舊版已登記的持續通知，升級保留為「每次都叫我」，將不同模式名單合併去重；舊按鈕 ID 保留相容。部署前舊足跡首次互動會加入追蹤並補上新按鈕和人名欄。
- 部署時已開緊的局不補 tag；未出卡計時重新開始。離線期間進出不能還原，結束時間可能係恢復時。
- 先持久化通知嘗試並用完一次性登記，再發訊息；若網絡失敗／結果不明，可能漏一次通知，但不自動重播或重複 ping。卡片更新失敗不回滾已儲存登記。

Bot 需要查看被監察語音房及在目標文字頻道查看、發送、嵌入連結和讀取歷史。私人語音參與者會出現在所設文字頻道，請選擇適合招募的路線。

驗證：`python -m unittest discover -s tests -v`，涵蓋30秒計時、散團、一次性／永續／切換、同遊戲跨模式、舊資料遷移、並發、取消、權限過濾、精確 allowed_mentions、名單分頁及重啟。

## 組隊流程整合（2026-11-08）

- 「更多玩法 → 社群互動 → 我的組隊通知」只顯示本人訂閱及已排隊的一次性通知；選取遊戲即可取消，不能更改其他會員。取消收據會在真正送出前再次核對，已開始處理／已送出的通知不能撤回。查看及取消不派 EXP。
- 散場先持久保存結束標記，停止未開始的通知。已知成功送出的小通知會改為「呢局已結束」，移除加入語音，保留足跡及下次預約入口；發送延遲返回亦會加入關閉核對。關閉失敗保留證據並退避重試，避免阻住其他訊息。
- 發召人卡前獨立保存發送紀錄。網絡 timeout、取消或不確定結果不自動重發；已知成功但 JSON 未完成保存，會先從紀錄採納訊息 ID。待查紀錄在語音清空後亦會保留，系統狀態顯示數量。
- Admin 可用 `/squad_recover channel:<語音房> message_id:<現有召人卡訊息ID>` 核對進行中未知發送；需作者、目的頻道、語音連結、唯一 session 按鈕及時間吻合。只連結現有卡，不重發或補 tag。無法確認的紀錄繼續待查。
- Discord gateway 斷線時暫停對賬／通知及關閉訊息；未發布的30秒計時重置，離線時間不當成連續在場。刪房後足跡仍保留最後已知遊戲及通知主題。

以上新關閉核對適用於已保存 delivery context／訊息 ID 的通知；舊版未記錄訊息 ID 的歷史通知不會掃描頻道或猜測修改。
