# 組隊卡與足跡名單

公開召人卡及足跡卡只顯示人數、遊戲／模式、語音位置或時段；不展開參與名單。「本局參與者」是唯讀的實際參與紀錄，「下次通知名單」是下一次／持續通知設定，兩者分開，查看參與者不會訂閱或發通知。

參與者按訊息 ID、伺服器及頻道存入持久 SQLite 表 `squad_participant_snapshots`；讀取需原伺服器、頻道可見、原 Bot 作者，私人分頁只供發起查看者使用，翻頁再次核對權限。新卡以成員 ID 保存，顯示時排除已離開、Bot 及不能查看頻道的成員。舊卡若只有名字，保留歷史文字，不猜測 ID、不補 tag。

既有追蹤中的舊卡在啟動刷新時先保存名單，再編輯原訊息收起名單。不新增公開訊息、不改訂閱、不補通知。原有訂閱按鈕 ID 不變，參與者按鈕使用獨立 ID。未追蹤或未保留參與者的舊卡不宣稱已有完整名單。

「我的組隊通知」取消／翻頁改為編輯原私人面板；不足兩頁不顯示翻頁鍵。一次性通知及持續通知的儲存、資格與派送規則維持原狀，通知仍在原遊戲頻道發出，並非只有被 tag 的人能看見訊息。

部署會重啟單一 Bot。持久資料及舊按鈕保持相容；短暫期間互動及自動建房可能失效，現有語音房不作修改。程式測試不能代替普通成員、Helper 或 iPhone 真人實測。
