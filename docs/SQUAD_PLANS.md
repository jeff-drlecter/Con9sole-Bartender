# 約一局整合候選版

目前程式已將現在玩、約定時間及我的約局放入同一私人入口；快捷列只保留「約一局」及獨立的小隊語音功能。舊 `team` 入口轉入同一選單，已存在的 Teams 活動卡繼續運作，沒有刪除或重新發卡。

PlanBook schema 2 保留既有 id、訊息、頻道、原有人數及報名名單。升級前以原始 bytes 備份 `squad_plans.json.before-unified-v2`；壞檔或未知 schema 停止載入，不改成空資料。舊 started 只代表預定時間已到：開始後2小時內轉待開局，更早的紀錄唯讀標為開局情況未核實。

預定時間後仍可加入、退出、改期、取消；2小時未開局則保留為未開局。即時招募保留6小時期限。稍後到保留名額但不宣稱已就緒。改遊戲、時間或模式保留舊資料及名單版本，報名轉為待重新確認，不冒充仍同意新安排。

發起人從原卡「名單／管理」按開局並確認。重新核對成員及語音權限，使用本分類自有小隊房或建立一間，不自動重用另一遊戲的自有房，不移動其他人；分類須已設定 SquadCards 場次記錄。空房先集合中，真人持續30秒才接入實際場次，沿用現有訂閱通知與去重。新建房前保存 attempt，回應不明時不盲目重建；若已取得並保存自有房可重新連接，否則由管理員核對或取消約局。

同一場使用原預約卡；如語音已產生自動召人卡，舊自動卡改為原卡連結。訂閱及發送收據保持同一 session，Bot 重啟不追補通知。刪除的約局卡不會被自動重發。完局沿用既有足跡門檻與收據，原卡保留報名歷史並連回實際參與足跡。

本次沒有開啟報名者的新提醒，私人加入回覆明確說明。公開卡仍供頻道有權限者查看；沒有新增 DM、公告、對象群組或角色 ping。普通 Helper 不能修改或替其他發起人開局。我的約局只列本人有關且目前仍能查看的卡。

驗證包括舊資料備份及重跑、四名報名者保存、壞檔停止、到時仍可操作、改期重確認、並發名額、跨遊戲房拒絕、同場不多發卡、語音／足跡綁定及未知建房不重播。程式檢查與正式 Discord、普通成員／Helper及真實iPhone驗收須分開回報。

部署前仍需核對持久資料與進行中的語音場次，升級會重啟單一 Bot instance，互動及自動建房可能短暫失效。不要用舊版程式直接覆寫新 schema。回復前先停寫，再依備份或經驗證的逆向轉換處理；不能為回復版本而抹走新報名或出席紀錄。

完整目標及未實作差異見 [整合設計](UNIFIED_SQUADS_REDESIGN.md)。

## 舊版流程及指令紀錄（非整合版現況）

# 預約約局

成員喺遊戲組隊文字頻道按「📅 約一局」，或用 `/約局`。管理員可用 `/約局面板` 喺目前頻道放置固定入口，之後可自行釘選。入口指令有執行時管理員檢查，Helpers 不會因身份組獲得配置權限。

表格只有遊戲、時間、平台／模式、已有人數、尚欠人數。遊戲按已知分區預填；模式和缺額可留空；已有幾人預設1並包括發起人。時間按香港時區解讀，例如「今晚22:00」、「明天22:00」、「2026-11-15 22:00」；不可默默將過去時間轉成翌日。只接受未來14日內，每人最多3個未開始約局。

公開卡顯示遊戲、平台／模式、Discord 當地時間、已有及尚欠人數和發起人；參與名單只經按鈕私人查看，其他成員可按「我參加」或「退出」。原有朋友屬發起人自行填報，與按卡加入名單分開計數；已計入原有隊伍的朋友不用重複按加入。沒有為未同意的人代登記或發通知。

只有發起人可改時間、模式及人數；管理員亦可取消。所有操作重新驗證伺服器、頻道、訊息及已驗證成員身分，普通 Helper 不可修改其他人的卡。報名操作用互斥鎖避免重複加入或超額；修改不可將目標縮至低於現有參加人數。

到點後關閉報名並更新卡；保留「查看名單」唯讀按鈕，不再提供修改或取消控制；不自動建立語音房，不觸發現有「下次叫我」／持續訂閱，不自動 ping 或 DM。這一版不含開局前提醒，避免額外通知。預約與現有進行中召人卡為兩個流程。

狀態保存在共用持久化資料目錄 `DATA_DIR/squad_plans.json`，只支援單一 Bot instance。重啟會恢復卡片按鈕及到期處理，已儲存但卡片更新失敗會每30秒重試。發卡前先保存 posting 狀態；網絡結果不明或儲存失敗不自動重發，避免重複卡。這類狀態需管理員核對，不會自動收編未知訊息。

驗證：`python -m unittest discover -s tests -p test_squad_plans.py -v`，涵蓋時區／日期解析、重複加入、原有人數、最後一位並發、修改及取消授權、重啟、到期、未知發送及儲存失敗。Discord 上線前仍需真人驗收入口、手機表格、加入退出與到期卡片；完整依賴及既有功能由 Python checks 驗證。


## 固定入口與既有卡片整理（2026-11-13）

管理員可在 `bartender使用指南`、`組隊與語音指南` 或 `如何加入不同遊戲分區✅` 使用 `/社群入口`。首次建立固定功能按鈕，再次執行只更新該 Bot 入口（掃描最近50訊息）；不改其他作者的教學。公共文字中性繁中；按鈕開啟個人回覆，不要求輸入 slash command。只讀教學頻道可開啟預約目的地選單，目的地仍須本人可發言且 Bot 有完整所需權限。無遊戲身份時引導至原生問卷，不自行派發遊戲角色。

`/約局整理` 僅管理員可用；只更新持久記錄內的約局及遊戲組隊頻道已置頂或最近50訊息內的 Bot 約局入口，不新增通知、不開語音、不改訂閱及成員角色。缺少或無法讀取的卡片只回報失敗。資料 schema 未改，既有按鈕 ID 保留。

部署仍會重啟單一 Bot instance，期間新按鈕互動及自動建房可能暫時失效；現有 Discord 語音房本身不依賴 Bot 持續連線。預約資料及語言偏好由持久檔案／Discord角色保留；部署後需核對指令同步及現場互動。


`/遊戲入口排序` 預設唯讀預覽，`action:套用` 只把各現有遊戲分類的唯一組隊文字頻道移到同分類文字／論壇最前；不改 category、權限或角色，也不處理封存／模板。原排序先備份到持久資料目錄。Discord 語音與文字分屬不同排序群組，此工具不將語音跨組移到最前。
