# 預約約局

成員喺遊戲組隊文字頻道按「📅 約一局」，或用 `/約局`。管理員可用 `/約局面板` 喺目前頻道放置固定入口，之後可自行釘選。入口指令有執行時管理員檢查，Helpers 不會因身份組獲得配置權限。

表格只有遊戲、時間、模式、已有幾人、仲差幾人。遊戲按已知分區預填；模式和缺額可留空；已有幾人預設1並包括發起人。時間按香港時區解讀，例如「今晚22:00」、「明天22:00」、「2026-11-15 22:00」；不可默默將過去時間轉成翌日。只接受未來14日內，每人最多3個未開始約局。

公開卡顯示遊戲、模式、Discord 當地時間、人數及發起人，其他成員可按「我參加」或「退出」。原有朋友屬發起人自行填報，與按卡加入名單分開計數；已計入原有隊伍的朋友不用重複按加入。沒有為未同意的人代登記或發通知。

只有發起人可改時間、模式及人數；管理員亦可取消。所有操作重新驗證伺服器、頻道、訊息及已驗證成員身分，普通 Helper 不可修改其他人的卡。報名操作用互斥鎖避免重複加入或超額；修改不可將目標縮至低於現有參加人數。

到點後關閉報名並更新卡；不自動建立語音房，不觸發現有「下次叫我」／持續訂閱，不自動 ping 或 DM。這一版不含開局前提醒，避免額外通知。預約與現有進行中召人卡為兩個流程。

狀態保存在共用持久化資料目錄 `DATA_DIR/squad_plans.json`，只支援單一 Bot instance。重啟會恢復卡片按鈕及到期處理，已儲存但卡片更新失敗會每30秒重試。發卡前先保存 posting 狀態；網絡結果不明或儲存失敗不自動重發，避免重複卡。這類狀態需管理員核對，不會自動收編未知訊息。

驗證：`python -m unittest discover -s tests -p test_squad_plans.py -v`，涵蓋時區／日期解析、重複加入、原有人數、最後一位並發、修改及取消授權、重啟、到期、未知發送及儲存失敗。Discord 上線前仍需真人驗收入口、手機表格、加入退出與到期卡片；完整依賴及既有功能由 Python checks 驗證。
