# Daily community tasks

One shared optional task per Hong Kong calendar day. Preserve the deployed five-task schedule through 2026-11-08; from 2026-11-09 choose among four successful bar actions, three committed text awards, one valid voice award, or successfully sent and persisted recruitment. Passive collection browsing is retired from the new rotation.

Text and voice progress counts committed source events, never multiplied XP. Existing source eligibility, shared text/activity cooldown, voice intervals and exclusions remain authoritative. Recruitment forms, cancelled actions, failed sends and failed persistence do not complete a task.

The fixed +5 bonus remains one durable ledger event per guild/user/HK day, included in the weekly board. It does not change engagement or voice cooldowns and has no Booster multiplier. Completion and reward receipt are displayed separately. A refresh reconciles completed tasks when eligible scoring is available; restarting or concurrent requests cannot award again. Rejoining excludes previous membership progress/completion, while retaining the daily bonus receipt to prevent repeated leave/rejoin claims.

For text/voice, capture the credited event time before awaits and reconcile the task before Discord role API work. Old-day source awards remain assigned to their event day across midnight. Daily panels are owner-bound and reject actions after HK midnight. No messages are stored for progress; only existing XP event metadata is queried, with a guild/user/source/time index.

Validation covers HK rollover, event count versus Booster XP, cooldown rejection, concurrent bonus claims across connections, excluded/off states, rejoin and timezone formats, failed drink/recruitment persistence, stale panels and role API failure across midnight.
