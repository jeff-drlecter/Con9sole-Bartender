# 成員功能小提示

已確認的產品方向：60% 權重介紹「單獨提及 Con9sole-Bartender → 開啟功能」；40% 權重介紹相關功能。這是每次抽選的權重，並非每天保證固定比例。

## 顯示範圍

- 公開：成功的飲品／請客／打氣訊息，附加一句，沿用原訊息、按鈕、作者／稀有度頁尾及 allowed_mentions。
- 私人：快捷選單及「更多」，使用成員已選語言；未選及台灣使用中性繁中，香港使用香港用語。
- 約局卡、開局／訂閱提醒、新聞、錯誤、管理日誌及 DM 沒有接入提示。
- 不另發提示訊息，不替其他 Bot 改訊息。音樂／Adventure 提示待入口、使用權限與有效指令核實後才加入。
- 目前只介紹已載入的對應功能；提示不授予任何遊戲區或管理權限。

## 頻率與儲存

每次合適回覆有 25% 機會抽選。公開按 guild＋channel、私人按 guild＋member 分開計算；每個範圍每日最多 2 次，最少相隔 30 分鐘，不連續重複同一句。按香港日期重置。

`member_hints.sqlite3` 位於既有持久資料目錄，跨功能及重啟共用計數。SQLite 交易先預留名額，防止並發超額；發送失敗或結果不明亦保留預留，不會為補發提示再次送訊息。互動去重紀錄保留兩天；不存用家訊息內容。

提示儲存或選取失敗時省略提示，主要功能繼續；等待提示最多 250 毫秒，避免拖延初次回覆。逾時但背景交易已完成者同樣保留預留名額。卡片接近 Discord 字數上限時省略提示，保留原文。設 `MEMBER_HINTS_ENABLED=0` 可停用提示；不需回復資料庫。預設啟用。

## 驗收及部署

測試須涵蓋香港日界、重啟、並發、重複互動、60/40 權重邊界、公開／私人隔離、語言、字數及主要訊息不受儲存失敗影響。Discord 實測限 Tester 區；不在普通頻道刻意製造提示或發公告；iPhone Mirroring 驗收按本輪要求略過。

程式測試通過不代表 Discord 實測或已部署。交 06 時附精確 commit、CI、未驗證項目。部署沿用既有活動閒置檢查、持久備份及單一 Bot 實例流程。

本機驗證：980 項測試通過（包含 13 項提示測試），Python 編譯及 diff 檢查通過。另修正既有分頁測試的資料偶發失敗：發起人不再與測試報名者重疊，避免相同時間的隨機約局 ID 排序選中自己的局；沒有改動約局功能。

未驗證：Discord 成員／Helper 實際顯示、正式環境持久儲存及手機排版。不得將本機模擬當作正式驗收。

用家訊息翻譯是另一項待定功能；本次沒有讀取、傳送或翻譯成員內容，亦未接駁翻譯 API。
